# Инструменты для запуска из исходников

В этой папке приложение ищет:

```
test\PAMFtool-win-x64.exe
test\ffmpeg\bin\ffmpeg.exe
test\ffmpeg\bin\ffprobe.exe
```

Бинарники не хранятся в репозитории. Скачайте:

- PAMFtool: https://github.com/ravenDS/PAMFtool
- FFmpeg: https://www.gyan.dev/ffmpeg/builds/ (essentials build)

Либо укажите пути вручную в окне **«Инструменты»** приложения.
